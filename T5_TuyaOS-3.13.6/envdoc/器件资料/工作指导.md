## 四、当前基线

| 项目 | 状态 |
|------|------|
| 主板 | **PCB8，六层**，建议成品厚 **1.6 mm** |
| 叠层（自上而下） | L1 器件 → L2 GND → L3 SIG → L4 PWR → L5 GND → L6 器件 |
| 关联原理图 | Schematic1 / P12 |
| 设计指导文档 | 部分仍写 PCB7/四层 → **以 PCB8 报告 + 硬件工程为准** |
| 显示屏 | ST7789T3 BOE 3.36"（见 `显示/`） |
| 语音模组资料 | 云知声 Hummingbird-M（见 `音频/uni_hb_m_solution-*`） |

### PCB8 量产前必改项（摘自检查报告）

1. L2/L4/L5 内层 **GND/PWR 敷铜** 落实  
2. **59% 器件在底层** → 评估调整到顶层或加强回流  
3. USB 差分阻抗（L6 约 104 Ω）→ 线宽/参考面优化  
4. **USB_VBUS** 不应长期走在 L3(SIG)，应走 PWR 层  
5. 原理图：**30 孤立线、278 无网名线** 清理

## 五、标准工作流程

### 5.1 归档新器件

1. 在对应分类目录新建文件夹：`厂商_型号/`  
2. 放入：PDF datasheet、立创编号、STEP/封装（如有）  
3. 若影响 PCB 布局，在 `硬件开发/` 更新 BOM 并在本目录 README 或设计指导中 **一句话说明用途**  
4. 命名避免仅「新建文件夹」；推荐 `类别_型号_日期`  

### 5.2 PCB 设计（EasyEDA）

1. **首次**：读 `设计指导/PCB7-*.md` 掌握布线优先级 P0→P5（PCB8 仍适用逻辑）  
2. 启动 Bridge：见 `.cursor/README.md`  
3. 对 AI：「嘉立创EDA，启动！」+ 引用 `PCB8-设计检查报告` 中的待改项  
4. 大改后运行/更新检查报告（`scripts/build_pcb8_report.py` 等）  
5. 板框从 `硬件开发/板框/` 导入，与结构 STEP 交叉验证  

### 5.3 布局辅助脚本

| 脚本 | 用途 |
|------|------|
| `run_layout_fast.py` / `layout_fast.py` | 快速布局 |
| `pcb7_u_layout.py` / `run_u_layout.py` | U 形板布局 |
| `scripts/analyze_usb_traces.py` | USB 走线分析 |
| `scripts/build_pcb8_report.py` | 生成 PCB8 检查报告 |

运行前确认 Python 环境与 EasyEDA 工程路径；输出 JSON/MD 纳入版本管理。

### 5.4 SolidWorks MCP

1. 打开 SolidWorks → 重启 Cursor MCP  
2. 参考 [SolidWorks-MCP-配置说明.md](设计指导/SolidWorks-MCP-配置说明.md)  
3. 本地验证：`scripts/test_solidworks_mcp_api.py`  

### 5.5 丝印资源

- 源文件：`丝印标识/*.svg`  
- 同步副本：`硬件开发/PCB/常用丝印/`  
- 修改时**两处同步**，避免 Gerber 不一致
