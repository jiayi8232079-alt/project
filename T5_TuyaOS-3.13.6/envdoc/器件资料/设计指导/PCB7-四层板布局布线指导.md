# PCB7（jiajia）四层板 — 布局与布线设计指导

> 适用工程：jiajia / schematic1·P1 / PCB7  
> 板型：U 形板框（所有焊盘须完全落在闭合板框内）  
> 层数：**4 层**  
> 量产规模：**约 1000 台/年**（中小批量，非海量消费级）  
> 状态：布局已定 → 布线阶段  

---

## 0. 板厚结论（建议直接采用）

| 项目 | 建议 |
|------|------|
| **成品板厚** | **1.6 mm**（推荐定版） |
| 备选 | 1.2 mm — 仅当结构高度卡死且已核算连接器共面度 |
| 不推荐 | 1.0 mm — U 形板 + FPC/USB，机械偏软、阻抗余量小 |

### 为何定 1.6 mm（结合 1000 台/年）

1. **工艺最成熟**：嘉立创四层 **1.6 mm** 阻抗叠层（JLC7628 / JLC2313）资料最全，USB 90 Ω 可直接用阻抗计算器，少踩坑。  
2. **机械可靠性**：U 形板、FPC 插拔、USB 口，1.6 mm 抗弯更好，售后返修成本远低于省几毛钱板费。  
3. **成本可接受**：1000 台/年属中小批量，单板面积不大时，1.6 mm 与 1.2 mm 差价通常 **每板仅几分到几毛钱量级**（以嘉立创下单系统实时报价为准），不值得为省厚牺牲可靠性。  
4. **过孔工艺**：1.6 mm 四层通孔厚径比更宽裕，比 1.0 mm 更少坏孔/电镀风险。  
5. **备货策略**：定版 1.6 mm 后 **同一 Gerber 返单**，避免改厚导致阻抗/装配全链路重验证。

**若结构极限高度不足**：先量 FPC/连接器机械叠高，再评估 1.2 mm；勿默认 1.0 mm。

---

## 1. 设计目标与模块划分

本板属于 **电源管理 + USB + 主控/T5（U32/U40 等）+ 摄像头/FPC + 连接器** 混合设计。

| 优先级 | 模块 | 典型网络 | 说明 |
|--------|------|----------|------|
| P0 | 地/电源 | GND、5V、AXP_*、VBAT、充电相关 | 决定回流与纹波 |
| P1 | USB 2.0 | USB_DP/DN、U_DP/U_DN | 差分 90 Ω，等长、少过孔 |
| P2 | 主控局部 | U40、U32、U1 电源脚与去耦 | 先芯片脚下再扇出 |
| P3 | 低速控制 | I2C_SYS、T5_RST、PWR_KEY、AXP_WAKEUP、UART/LOG | 短、远离电源噪声 |
| P4 | 摄像头/FPC | CIS_*、DVP_*、SCL/SDA_CAM、FPC1 | 并行线多，放后 |
| P5 | 其余 IO / CN | GPIO、连接器 | 按《T5系列接口列表V2》分批 |

**布线顺序：** P0 → P1 → P2 → P3 → P4 → P5。

## 2. 四层板层叠（嘉立创，板厚 1.6 mm）

### 2.1 推荐叠层

| 层 | 用途 | 说明 |
|----|------|------|
| **L1 顶层** | 器件 + 关键信号 | USB、芯片短出线、FPC 扇出（与当前布局一致） |
| **L2 内层** | **完整地（GND）** | 主参考平面；U 形区域内连续铺铜 + 缝合过孔 |
| **L3 内层** | **电源分区** | 5V / 3V3 / 电池等；避免大面积挖空 |
| **L4 底层** | 次要布线 + 补地 | 少量底层器件；避免长距离高速走底层 |

### 2.2 叠层原则（嘉立创文档）

- 主芯片相邻层为地平面。  
- 信号层避免两信号层直接相邻（L1/L4 间有 L2 地，合理）。  
- 电源与地相邻，降低电源阻抗。  
- **阻抗**：下单选 **1.6 mm + 标准四层结构（JLC7628 等）**，用嘉立创阻抗计算器算 USB 线宽/线距。

### 2.3 USB 差分（90 Ω）

- 目标阻抗 **90 Ω**（差分）。  
- 等长（对内）、≤45°、少换层、两侧包地。  
- 下单勾选 **阻抗管控**（产品级建议保留，1000 台/年摊销成本低）。

## 3. 嘉立创工艺能力（四层 · 产品级建议）

> 具体参数与价格以 [嘉立创 PCB 下单页](https://www.jlc.com) 实时选项为准。

| 项目 | 建议（1000 台/年） | 说明 |
|------|---------------------|------|
| 层数 | 4 层 | 已定 |
| 板厚 | **1.6 mm** | 见第 0 节 |
| 线宽/线距 | **6/6 mil** | 稳定工艺；5/5 mil 需确认工艺档 |
| 过孔 | 内径 0.3 mm / 外径 0.6 mm | 常规；电源地多孔并联 |
| 铜厚 | 1 oz | 大电流电源局部加宽铺铜 |
| 阻焊 | 绿油（默认） | 按外观要求 |
| 表面处理 | **沉金 ENIG**（推荐） | FPC/细间距焊盘更稳；1000 台/年值得 |
| 备选表面处理 | 有铅喷锡 HASL | 仅降本且接受共面度风险时 |
| 阻抗 | 勾选（USB） | 与 1.6 mm 叠层配套 |
| 盘中孔 | 4 层通常不免费 | 按普通工艺过孔设计即可 |

## 4. 成本与下单策略（1000 台/年）

### 4.1 量级判断

- **1000 台/年** ≈ 每月几十到一百多块 PCB，属 **中小批量**，不是消费类十万级。  
- 成本重点：**一次把设计做对 + 返单稳定**，而不是压到 1.0 mm 极限薄。

### 4.2 费用构成（概念）

| 因素 | 建议 |
|------|------|
| 板费 | 按面积 × 平米价（四层高于双层） |
| 工程费 | 新单通常有；**返单可省** |
| 表面处理 | 沉金 > 喷锡 |
| 阻抗 | 小附加费，建议保留 |
| 加急 | 量产备货提前下单，少用加急 |

### 4.3 实操建议

1. **首版**：打样 5–10 pcs 验证（1.6 mm + 沉金 + 阻抗）。  
2. **小批**：每批 100–300 pcs 拼板或单板，**同一文件返单**。  
3. **年约 1000 台**：可 2–4 次下单覆盖全年，避免年底单批巨大加价。  
4. **SMT**：若嘉立创 SMT，板厚 1.6 mm 与标准钢网工艺兼容性好。  
5. **文档**：Gerber、钻孔、阻抗说明、叠层截图一并归档，便于返单。

### 4.4 板厚与单价（定性）

| 板厚 | 相对成本 | 适用 |
|------|----------|------|
| 1.0 mm | 略低 | 空间极限、非主连接口受力 |
| 1.2 mm | 中等 | 结构略紧时的折中 |
| **1.6 mm** | 标准价、最常用 | **本产品推荐** |

## 5. U 形板框专项规则

1. 所有焊盘四角须在 U 形闭合轮廓内，不得伸入 U 口。  
2. 避免沿 U 口方向跨区长飞线。  
3. L2 地平面连续；L1/L4 分割处 **地过孔栅栏**（约 5–10 mm）。  
4. 高速线优先顶层；底层仅短线与地过孔。

---

## 6. 布局（已定板后微调）

| 项 | 建议 |
|----|------|
| 去耦 | 紧贴 IC 电源脚，过孔就近接地 |
| 大 IC | U40/U32/U1 出线朝向 FPC/CN |
| 连接器 | FPC1、CN 朝向 U 形直边 |
| 发热 | PMIC/充电远离 CIS/FPC |
| 底层 | 被动件为主，高速不走长距离底层 |

---

## 7. 布线规则摘要

### 地 / 电源

- L2 完整地 + L1/L4 铺地过孔连接。  
- 电源树：输入 → PMIC → 各域；避免细线串供。  
- 数字/模拟地按原理图单点相连。

### USB / I2C / 摄像头

- USB：按阻抗线宽，对内等长，包地。  
- I2C/UART/复位：短、少过孔。  
- DVP/FPC：组内等长，时钟最短，FPC 成束出线。

## 8. DRC 与交付检查

- [ ] 板厚 1.6 mm 与下单、EDA 层叠一致  
- [ ] USB 阻抗线宽与计算器一致  
- [ ] 焊盘均在 U 形板框内  
- [ ] 去耦距电源脚 < 3 mm（目标）  
- [ ] 设计规则 ≥ 6/6 mil（或所选工艺）  
- [ ] 出 Gerber 前嘉立创 DFM 预览
