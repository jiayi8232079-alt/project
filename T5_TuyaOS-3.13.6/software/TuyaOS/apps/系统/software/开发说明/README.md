# 陪了个伴 · 开发说明（系统总文档）

> 这是整套「陪了个伴」系统的**唯一开发入口文档**。
> 面向：后端 / 前端（小程序·后台·App）/ 嵌入式 / DevOps / 测试 / 产品，以及**协作的其他 AI**。
> 目标：任何人（或 AI）只要从本文件夹读起，就能完整理解「系统是什么、有哪些功能、代码在哪、怎么继续开发」。

**最近整理日期：** 2026-06-24
**整理基线：** 已对照当前真实代码核对（后端 38 模块 / 66 实体、admin Vue3、UniApp 小程序、Flutter App），并补充对齐 V4.3《AI 家庭与社区协同版》商业计划书。

---

## 0. 一句话介绍

**陪了个伴** = 「医疗陪诊调度 + 老人健康管理 + AI 陪护机器人 + 分层多租户三门户」四位一体的养老健康服务平台。
四个客户端（微信小程序 / Flutter App / Vue 管理后台 / T5 陪护机器人）共用**一套 NestJS 后端**。

## 3. 仓库顶层结构速查

```
software/         # 软件端（本文档位于 software/开发说明/）
├── backend/      # NestJS 后端（唯一后端，四端共用）
├── admin/        # Vue3 + Element Plus 管理后台（三门户同工程）
├── UniApp/       # 微信小程序（用户/老人/家属/护工/机构）
├── mobile/       # Flutter App（Android/iOS，C 端为主）
├── deployment/   # 数据库 SQL、迁移脚本、导出脚本
├── docs/         # AI Prompt / MCP 对接规范等专题规格
├── T5 E1 模组/   # 涂鸦 T5-E1 硬件资料（规格书/原理图/引脚表）
└── 开发说明/      # 👈 本文件夹：整理后的开发总文档

# 仓库根（peiban/）另含：
robot/            # 机器人端（固件/控制/硬件设计）
contracts/        # 机器人↔后端 接口契约
AGENTS.md         # AI 协作总入口（各端另有 AGENTS.md）
```
