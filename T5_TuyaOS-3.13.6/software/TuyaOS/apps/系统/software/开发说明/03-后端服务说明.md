# 03 · 后端服务说明（NestJS）

> 上层导航见 [`README.md`](./README.md)。本篇回答：**后端有哪些模块、各自的接口前缀、横切基础设施、启动与配置**。
> 数据实体见 [`04-数据模型与数据库.md`](./04-数据模型与数据库.md)；AI/设备/多租户/计费细节见 `08`/`09`/`10`。

代码位置：`backend/`（NestJS 11 + TypeScript + TypeORM + MySQL + Redis）。

---

## 1. 目录结构

```
backend/src/
├── main.ts                  # 启动入口（端口/CORS/helmet/Swagger/全局管道）
├── app.module.ts            # 根模块：注册 38 业务模块 + TypeORM + Redis + Throttler
├── app.controller.ts        # 健康检查等
├── common/                  # 横切基础设施（见 02 架构 §3）
│   ├── contexts/            # RequestContext (ALS)
│   ├── entities/            # BaseEntity / TenantAwareEntity
│   ├── guards/              # TenantGuard 等
│   ├── interceptors/        # RequestContextInterceptor
│   ├── subscribers/         # TenantSubscriber
│   ├── decorators/          # @SkipTenant 等
│   ├── redis/               # RedisModule / RedisService
│   ├── throttler/           # RedisThrottlerStorage
│   └── utils/               # tenant-query.helper 等
├── entities/                # 66 个实体（见 04）
├── database/                # db-bootstrap：启动兜底建列/seed
├── modules/                 # 38 个业务模块（见下）
└── types/                   # 全局类型
```

辅助目录：`backend/migrations/`（TypeORM 迁移）、`backend/scripts/`（脚本，如 set-local-ai-config.sql）、`backend/docs/`（专题：本地 AI 模型 / 多角色工作台 / 用药严格模式 / 列加密）、`backend/uploads/`（本地上传）。

## 3. 主要 API 速查（按模块）

> 这里给最常用的端点；**全部 REST 端点（约 290 个）见 [`18-API接口全量清单.md`](./18-API接口全量清单.md)**。完整签名以各 `*.controller.ts` + Swagger `/api-docs` 为准。

**auth（`/auth`）**：`POST /auth/wechat-login`、`/auth/sms/send-code`、`/auth/sms-login`、`/auth/apple-login`、`/auth/admin-login`（限流 5/min 防暴破）、`/auth/logout`。

**user（`/users`）**：`GET /users/me`、`GET /users/me/service-targets`、`GET /users/service-targets/:id`、服务对象 CRUD。

**order（`/orders`）**：`POST /orders`（下单）、`GET /orders`、`GET /orders/:id`、`POST /orders/:id/review`、取消/派单/状态流转；`/public/*` 公开分享。

**professional-service（`/professional-services`）**：`GET /professional-services/public`、`GET /professional-services/public/code/:code`。

**medication（`/medication-reminders` `/medication-executions`）**：`GET /medication-reminders/my`、`POST /medication-executions/check-in`（打卡）。

**alert（`/alerts`）**：`GET /alerts`、`GET /alerts/:id`、`GET /alerts/pending-count`、`POST /alerts/:id/ack`（确认）。

**family（`/family` `/public/family`）**：`GET /family`、`/family/:id/members`、`/family/:id/invite-code`、`POST /family/join`、`GET /public/family/by-invite-code/:code`、`/family/:groupId/elders`。

**device（`/devices`）**：`GET /devices/me/list`、`POST /devices/bind`、`GET /devices/:id`、`POST /devices/:id/dp`、`POST /devices/:id/self-control`、`/ota/check` `/ota/upgrade`、`GET /devices/:id/events`、`/devices/events/safety`；admin：`POST /devices/:id/mock-event` `mock-online`。

**ai-dialog（`/ai-dialogs`）**：`GET /ai-dialogs`、`GET /ai-dialogs/sessions/:id`、`POST /ai-dialogs/logs`、`POST /ai-dialogs/sessions/:id/finish`、`PATCH .../qa-status`。

**billing（`/billing`）**：`GET /billing/plans`、`/billing/subscriptions`（CRUD+renew+cancel）、`GET /billing/usage`、`/billing/invoices`（申请/开票/驳回）。

**tenant（`/tenants`）**：`GET /tenants/me/list`、`/tenants`（CRUD）、`/tenants/roles` `/permissions` `/members`、`/tenants/tree` `/:id/descendants|ancestors|children|breadcrumbs`、`POST /:id/move`。

**stat-dashboard（`/dashboard`）**：四门户（平台/政府/社区/企业）聚合大屏数据。

**mcp（`/mcp`）**：`POST /mcp` JSON-RPC（initialize / tools/list / tools/call）。详见 `08`。

## 4. 启动与配置

### 4.1 本地启动
```bash
cd backend
cp .env.example .env        # 改 DB/JWT/微信等
npm install
NODE_ENV=development npm run start:dev   # 自动建表 + bootstrap seed
# Swagger: http://localhost:3000/api-docs
```
生产：`NODE_ENV=production npm run start:prod`（先跑迁移 SQL，见 `11`）。

### 4.2 启动兜底（db-bootstrap + tenant bootstrap）
- `DbBootstrapModule`：启动时兜底建列 / 基础数据。
- `TenantModule` `OnApplicationBootstrap`：自动插入默认平台租户（id=1）+ 内置角色 + 权限点，并 `ensureTenantColumns()` 给业务表补 `tenant_id`；层级 seed（平台→浙江民政→丽水民政→阳光养老院→莲都分院，幂等）。

### 4.3 关键环境变量（节选）
| 变量 | 用途 |
|---|---|
| `NODE_ENV` / `DB_SYNCHRONIZE` | 是否允许 TypeORM 自动改表（生产须 false） |
| `DB_HOST/PORT/USERNAME/PASSWORD/DATABASE` | MySQL |
| `DB_SLAVE1_HOST/...` | 读写分离从库（可选，配了才启用） |
| `REDIS_HOST/PORT/PASSWORD` | Redis（缓存/限流/队列/实时 adapter） |
| `JWT_SECRET` / `JWT_EXPIRES_IN` | JWT |
| `WECHAT_APPID/SECRET` | 小程序登录 |
| `COS_*` | 腾讯云对象存储 |
| `TENCENT_SMS_*` | 短信 |
| `AI_*` / `OPENAI_*`（DeepSeek/豆包/Ollama） | AI 模型（见 `backend/docs/local-ai-model.md`） |
| `AI_GATEWAY_HMAC_SECRET` / `TUYA_SIGNATURE_KEY` | MCP 网关签名（见 `08`） |

完整变量见 `backend/.env.example` / `.env.local.example`。环境变量索引见 [`11-部署与运维.md`](./11-部署与运维.md)。

## 5. 编码约定（后端）

- 新表一律继承 `TenantAwareEntity`（自带 `tenant_id`），命名小写下划线。
- 新接口默认挂 `@UseGuards(JwtAuthGuard, TenantGuard)`（注册/登录/公开分享/平台超管除外，用 `@SkipTenant()`）。
- 查询统一用 `applyTenantFilter` / `withTenantWhere`（层级用 `applyTenantScope`）。
- 写操作自动审计（无需手写）；敏感字段用列加密。
- 详细规范与「新增一个模块」步骤见 [`12-开发指南与规范.md`](./12-开发指南与规范.md)。
