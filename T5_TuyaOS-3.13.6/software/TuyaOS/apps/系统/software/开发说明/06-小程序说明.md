# 06 · 微信小程序说明（UniApp）

> 上层导航见 [`README.md`](./README.md)。本篇回答：**小程序有哪些页面、如何分包、四类角色入口、与后端如何对接**。
> 代码位置：`UniApp/miniprogram/`（微信小程序原生 + TypeScript + Skyline；自定义 tabBar）。

> 命名说明：目录虽叫 `UniApp`，但当前是**微信小程序原生工程**（`app.json` + 自定义组件 + 分包），用微信开发者工具打开 `UniApp/` 即可。

---

## 1. 目录结构

```
UniApp/miniprogram/
├── app.json            # 全局：页面注册 / 分包 / tabBar / 预加载
├── app.ts / app.less   # 全局逻辑与样式
├── config.ts           # 后端基址（api.qiaoguo.vip）等
├── pages/              # 主包页面（见 §2）
├── custom-tab-bar/     # 自定义底部 tabBar（custom: true）
├── components/         # 公共自定义组件
├── utils/              # 工具（storeInfo / share-cover 等）
├── assets / images/    # 静态资源
├── miniprogram_npm/    # 构建后的 npm 包
└── typings/            # 类型声明
```

后端基址：`https://api.qiaoguo.vip`（见 `config.ts`），鉴权走 JWT（`wx.login → POST /auth/wechat-login`）。

## 2. 主包页面 + 4 个 tab

底部 tabBar（自定义，custom）4 项：**首页 / 服务 / 健康 / 我的**。

主包页面（`app.json` pages）：
`index/index`(首页聚合) · `service/service`(服务列表) · `health/health`(健康首页) · `mine/mine`(我的) · `login/login` · `elder/home/home`(老人端极简首页) · `webview/webview`(通用 H5 容器) · `agreement/agreement`(协议) · `aftercare/aftercare`(诊后随访) · `ai-consult/ai-consult`(AI 问诊) · `health/add-member/add-member`(添加被服务人) · `membership/membership`(会员) · `checkup/checkup`(体检下单) · `inpatient/inpatient`(住院下单) · `escort/escort`(陪诊下单) · `consult/consult`(咨询下单) · `expert/expert`(专家) · `expert-match/expert-match`(专家匹配) · `hospital-map/hospital-map`(医院地图)

## 4. 四类角色入口（一套小程序多端）

| 角色 | 入口 | 关键页面 |
|---|---|---|
| **用户 / 下单人** | 首页 / 服务 | 下单（escort/checkup/inpatient/consult）→ order 分包 |
| **老人 / 服务对象** | `elder/home`（极简大字） | 用药提醒、一键操作 |
| **家属 / 监护人** | `family/dashboard` 看护盘 | 老人状态 + 告警 + 用药 + 设备 + AI 对话摘要 |
| **护工 / 陪诊员** | `workbench` 分包 | 抢单/接单、排班、签到、时间线、费用、钱包 |
| **机构 / 平台** | `admin` 分包 | 大盘/订单/客户/护工/财务/配置（轻量管理，重管理仍用 Vue 后台） |

## 5. 与后端对接要点

- 基址/鉴权：`config.ts` 配 `api.qiaoguo.vip`，Bearer JWT。
- 设备控制「机器人移动」= 云台 `ptz_control` DP，默认走后端 `POST /devices/:id/dp`（最快，接口已就绪）；视频/配网才上涂鸦 SDK。
- 实时告警：小程序 WebSocket 对接后端 `realtime`。
- 接口前缀对照见 [`03-后端服务说明.md`](./03-后端服务说明.md)；与 App 的功能/接口对照见 [`13-功能清单与开发状态.md`](./13-功能清单与开发状态.md)。

## 6. 开发状态

小程序是**功能最全的端**（≈79 页 / 22 分包），覆盖用户/老人/家属/护工/机构全角色。新增设备(`device`)与 AI 对话(`ai`)分包对应机器人能力。后续重点：设备真实配网（涂鸦 SDK/H5 桥接）、AI 对话摘要接真实数据。
