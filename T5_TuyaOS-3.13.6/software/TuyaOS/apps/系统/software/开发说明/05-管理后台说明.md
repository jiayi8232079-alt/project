# 05 · 管理后台说明（admin / Vue3）

> 上层导航见 [`README.md`](./README.md)。本篇回答：**后台有哪些页面、三门户如何区分、数据大屏怎么做、目录结构与路由**。
> 代码位置：`admin/`（Vue 3.5 + Element Plus 2.13 + Vite 5 + Pinia 3 + vue-router 4 + ECharts 6/echarts-gl）。

## 1. 目录结构

```
admin/src/
├── main.ts            # 入口（注册 Element Plus / Pinia / Router / 自动导入）
├── App.vue
├── api/               # 按模块的接口封装（tenant/billing/device/ai-config/ai-dialog/portal-dashboard...）
├── views/             # 页面（按业务域分目录，见下）
├── components/        # 公共组件
│   ├── layouts/Sidebar.vue      # 侧边菜单（按门户/角色渲染）
│   ├── charts/ChinaMap.vue      # 地图可视化（政府门户）
│   ├── screen/ScreenMap.vue / ScreenPanel.vue   # 数据大屏组件
│   └── tenant/TenantTreeSelect.vue              # 租户层级树选择器
├── router/index.ts    # 路由表（菜单 + 权限 meta）
├── stores/            # Pinia（用户/门户/权限等）
├── config/            # 环境与常量
├── constants/
├── utils/             # portal.ts（门户判定）/ region.ts（行政区划）等
└── assets/styles/     # 主题（variables.scss / index.scss）
```

启动方式（两种接口环境）见 `admin/README.md`：`npm run dev`（本地后端 `localhost:3000`）/ `npm run dev:online-preview`（线上 `api.qiaoguo.vip`，只读为宜）。

## 3. 三门户机制（同一工程，不部署三套）

后台是「**一套 Vue 工程**」，按当前登录用户的 `tenant.scopeType/tenantType` + `role` 动态决定可见菜单与默认大屏：

| 门户 | 使用者 | 看到什么 |
|---|---|---|
| **平台总后台** | 超管 / 运营 / 财务 / 客服 | 全量（订单/客户/护工/财务/配置/审计/租户/计费/AI 质检 + 平台大屏） |
| **政府门户** | 民政 / 政府 | 按行政层级（path/depth）聚合辖区大屏（ChinaMap 地图下钻） |
| **社区机构门户** | 机构管理员 / 值班员 | 本机构居民设备、告警值班台、上门工单 |
| **企业 B 端门户** | 采购方账号 | 数据看板、SLA 报表、合同续约、对账单 |

- 判定逻辑：`utils/portal.ts`；菜单渲染：`components/layouts/Sidebar.vue`；行政区划：`utils/region.ts` + `element-china-area-data`。
- 大屏数据来自后端 `stat` 模块（`/dashboard/*`，见 `03`）+ `api/portal-dashboard.ts`。

详见 [`10-多租户三门户与计费.md`](./10-多租户三门户与计费.md)。

## 4. 数据大屏技术点

- 图表：ECharts 6 + echarts-gl（3D/地图）+ `@kjgl77/datav-vue3`。
- 自适应：`autofit.js`（大屏分辨率自适应）。
- 地图：`ChinaMap.vue` / `ScreenMap.vue`，政府门户按区划下钻。
- 导出：`xlsx` + `file-saver`（报表导出）；`docx-preview`（单据预览）。

---

## 5. 与后端的对接

- 统一 axios 实例（`admin/src/api/`），Bearer JWT；环境基址见 `.env.*`（`.env.online-preview` / `.env.production.example`）。
- 新增视图的标准做法：在 `api/` 加接口封装 → `views/` 写页面 → `router/index.ts` 注册路由与菜单 meta → 必要时在 `stores/` 加状态。
- 自动导入：`unplugin-auto-import` + `unplugin-vue-components`（`auto-imports.d.ts` / `components.d.ts` 自动生成，勿手改）。
