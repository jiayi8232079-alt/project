> 与软件侧的对应见 [`09-设备与硬件接入.md`](./09-设备与硬件接入.md)（device 模块 / 涂鸦云 / 固件规划）。

## 1. 主控模组：涂鸦 T5-E1 系列

| 项 | 说明 |
|---|---|
| 芯片平台 | 涂鸦 **T5 AI** 芯片（TuyaOS，支持 Wukong AI 语音方案） |
| 无线 | Wi-Fi 2.4G + BLE（板载 PCB 蛇形天线 / IPEX 外接天线二选一） |
| 模组型号 | **T5-E1**（板载天线版）/ **T5-E1-IPEX**（IPEX 外接天线版） |
| 供电 | 模组 `3V3` 引脚供电（开发板用 DC-DC 5V→3.3V/2A） |
| 典型外设 | LCD 屏（RGB/I8080/SPI）、双麦克风（I2S/DMIC）、扬声器功放、DVP 摄像头、TF 卡、USB |
| 开发板 | T5AI-Board V102、T5AI-Board-EYES（带屏/摄像头方案） |

**E1 与 IPEX 版差异**：T5-E1 的 P49/P50 脚位为 GND；T5-E1-IPEX 把 P49/P50 引出（多两路 GPIO/LCD 红色数据位），并改用 IPEX 天线座。

## 2. 关键功能引脚（T5-Board V102 实际接法）

> 完整 290 行引脚映射见 `T5 E1 模组/T5系列接口列表V2.xlsx`（含 T5-E1 / T5-E1-IPEX / T5-Board / T5-POCKET 四列功能）。下表为机器人开发最常用的功能组。

| 功能组 | 引脚 | 用途 |
|---|---|---|
| 电源 | `3V3` / `GND` / `RST` | 供电 / 地 / 硬复位（10K 上拉 + SW1） |
| 烧录调试 | `DN`/`DP`(USB) → CH342F、`RXD`/`TXD`=UART0、`P0`/`P1`=LOG_UART | USB 转双串口，日志 + 下载 |
| 系统 I2C | `P20`=I2C_SYS_SCL、`P21`=I2C_SYS_SDA | 触摸屏 / 传感器总线 |
| 音频输出 | `P25`=SPK_CTL（功放 CS8302M SHDN 使能）、I2S/扬声器 | 语音播报（TTS） |
| 音频输入 | `P6-P9`（I2S0 / DMIC：SCK/SYNC/DIN/DOUT、DMIC_CLK/DAT）、麦克风 M1 | 远场拾音（语音唤醒/对话） |
| 摄像头 DVP | `P27`=MCLK、`P29`=PCLK、`P30`=HSYNC、`P31`=VSYNC、`P33`=D1…（DVP_D0-D7，22Ω 串联） | 视频通话 / 人脸追踪 |
| LCD 显示 | `P44`=LCD_SCLK、`P45`=LCD_CS、`P46`=LCD_RST、`P47`=LCD_SDI、`P19`=LCD_D/C；RGB/I8080 数据位 P14-P18/P41-P47 | 表情动画 / 屏显 |
| TF / SD 卡 | `P2`=SD_SCK、`P3`=SD_CMD、`P4`=SD_D0、`P5`=SD_D1（与 SPI Flash 复用） | 断网降级语音 / 资源存储 |
| 按键 / 摇杆 | `P9`=BTN、`P12`=ADC_U/D、`P13`=ADC_L/R、SW5=ADC_KEY、SW1=RST | 物理按键 / 方向输入（可作 SOS 键） |
| 4G（POCKET 版） | `DN`/`DP`=USB_4G_DM/DP | 独立 4G 联网（不依赖家庭 WiFi） |

## 3. 开发板硬件 BOM 要点（T5-Board V102）

> 完整 BOM 见 `T5 E1 模组/T5-Board_V102_器件清单与引脚表.xlsx`。关键器件：

| 模块 | 器件 | 说明 |
|---|---|---|
| 电源输入 | USB Type-C 母座 + 2A 保险丝 + SS34 防反接 | 5V 输入 |
| DC-DC | MP1584/SY8088 同步降压 + 4.7µH 电感 | 5V→3.3V/2A 给模组 |
| USB 转串口 | CH342F（USB 转双 UART，QFN-24）| 烧录/调试 |
| 主控 | T5-E1-IPEX Module（U6）+ 磁珠/去耦 | WiFi/BLE 主控 |
| 天线 | 板载蛇形天线 ANT1 + IPEX 座（YC-901001）| 2.4G |
| 排针 | P8/P9（2×9）、P10（2×8 DVP 摄像头）、P11（SD/SPI） | GPIO/LCD/摄像头/SD 引出 |
| 音频 | 硅麦 M1 + MICBIAS、扬声器功放 CS8302M（U2） | 拾音 + 播报 |
| 交互 | IO-LED（D3）、ADC 按键（SW5）、RST（SW1）、全测试点 ESD（ESD5V0D3） | 调试与防护 |

## 4. 机器人形态映射（硬件能力 → 产品能力）

| 产品能力（见 `15`/`09`） | 依赖硬件 | 引脚/器件 |
|---|---|---|
| 表情/屏显 | LCD 屏 | LCD_SCLK/CS/RST/SDI/DC（P44-P47, P19） |
| 语音唤醒 + 陪聊 | 麦克风阵列（远场） | DMIC/I2S0（P6-P9）+ M1 |
| 语音播报（TTS） | 扬声器 + 功放 | SPK_CTL(P25) + CS8302M |
| 视频通话 / 人脸追踪 | DVP 摄像头（带物理隐私开关） | DVP（P27-P33） |
| SOS 一键求助 | 物理按键 | BTN(P9) / ADC 按键（走固件 `report_dp("sos",1)`，不经 AI） |
| 断网降级语音 | TF 卡本地音频 | SDIO（P2-P5） |
| 独立联网 | 4G 模组 | USB（POCKET 方案） |
| 云台/方向（可选） | 舵机 + 方向输入 | ADC 摇杆（P12/P13）+ PWM |

> 注：商业计划书（`15`）定义的机器人形态含「4G 独立联网 + SOS 物理键 + 摄像头物理隐私开关 + 环境/跌倒感知联动」；具体量产形态由 ODM 确定，平台聚焦 AI 与服务（不做硬件重资产）。

## 5. 涂鸦平台配置（与硬件配套）

机器人需在涂鸦开发者平台完成：功能定义（标准 DP：volume_set/mute/battery/charge/fault/ptz_control 等 + 自定义 `sos`）→ 硬件开发（选 T5-E1 模组，领 UUID+AuthKey）→ 智能体（DeepSeek + 系统 Prompt + 知识库 + 工具集）→ AI 控制指令（DP + 表情/动作/人脸追踪非 DP 指令）→ 自定义 MCP 服务（StreamableHTTP 指向后端 `/mcp`）。
详细顺序与固件 `cmd_cb` 实现见 [`09-设备与硬件接入.md`](./09-设备与硬件接入.md) §5。
