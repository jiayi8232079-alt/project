# AGENTS.md · 机器人端（robot/）

> 给硬件 / 机器人方向的 AI 与开发者。负责人 @jiayi8232079-alt。先读仓库根 [`../AGENTS.md`](../AGENTS.md)。

## 这是什么
基于**涂鸦 T5-E1 模组 + Wukong AI 3.0** 的桌面陪护机器人：屏幕表情 + 双麦 + 喇叭 + 摄像头 + 云台，配毫米波跌倒雷达。
经**涂鸦云**中转与后端通信（设备消息上行 / 指令下行 / WebRTC 视频）。**固件待开发，资料齐全。**

## 目录
- `firmware/` 涂鸦 TuyaOS 固件（对应文档里的 `firmware-companion-t5`，待建）
- `control/` 控制 / 上位机程序
- `hardware-design/` 电路 / PCB / 结构件（大文件走 Git LFS，先 `git lfs install`）
