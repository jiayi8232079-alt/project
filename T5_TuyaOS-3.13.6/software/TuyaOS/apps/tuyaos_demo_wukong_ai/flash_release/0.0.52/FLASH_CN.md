# 0.0.52 烧录与验收

## 1. 烧哪个文件？

| 用途 | 文件 | 说明 |
| --- | --- | --- |
| **整片烧录（推荐）** | `tuyaos_demo_wukong_ai_QIO_0.0.52.bin` | 含 bl2 + CP + AP，表情 UI 在 AP |
| OTA 全量 | `output/0.0.52/..._UA_0.0.52.bin` | 云端/工具 OTA，不是 IDE 右键 Flash 首选 |
| OTA 差分 | `output/0.0.52/..._UG_0.0.52.bin` | 需基线版本匹配 |

**本目录只放 QIO，避免烧错分包。**

## 2. Wind IDE 烧录步骤

1. Type-C 连接板子，串口映射到 Linux（常见 `ttyACM0`）。
2. 右键本目录下的 **QIO** → **Flash App**。
3. 若提示 `Waiting Reset ...`，按板子 **RST**。
4. 终端出现烧录完成后再断电重启一次。

## 3. 怎么确认「都烧进去了」？

我无法远程看到你板子，请按下面 **四项全过** 才算成功：

### ① 工具侧

- IDE 烧录日志无 `failed` / `error`。
- 烧录前可核对 MD5（与本目录 `MANIFEST.json` 一致）：
  - MD5: `b29bb73834bba12e4f6bdf14fc6f6a8c`
  - 大小: **3941728** 字节（约 3.76 MiB）

### ② 串口版本（必做）

打开串口 115200，上电后搜索：

```text
tuyaos_demo_wukong_ai:0.0.52
```

或日志里的 `name:...` / `sw_ver` 含 **0.0.52**。  
若仍是 **0.0.51** 或更早 → **没烧成功或烧错文件**。

### ③ 分区含义（QIO 里有什么）

本版 QIO 打包包含：

- **bl2**（引导）
- **cp**（约 973 KB，通信/音频等）
- **ap**（约 2.5 MB，**含 LVGL 表情 UI + person_tracker**）

只烧 UA/UG 或只更新了 CP 而 AP 仍是旧的 → 表情不会变。

### ④ 功能冒烟

| 项 | 预期 |
| --- | --- |
| 唤醒/对话 | 表情随状态变化（非固定一张脸） |
| 人移动 | 头/电机有跟随（YUV 肤色检测，非 ML） |
| 长时间运行 | 观察是否仍频繁断电（PMIC 阈值已改为 3000mV） |

## 4. 常见「以为烧了其实没有」

1. 烧的是 `output/0.0.51` 旧 QIO。
2. 编译失败只更新了 CP，`bk7258_ap/app.bin` 仍是旧日期。
3. 用了 **UG** 差分包，基线版本不对。
4. 烧录中断未 RST，IDE 显示完成但 flash 不完整。
