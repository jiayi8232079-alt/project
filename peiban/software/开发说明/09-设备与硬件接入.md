## 2. 接入链路（经涂鸦云中转）

```
机器人(T5-E1)  ──音视频/DP/事件/视觉跌倒──▶  涂鸦云  ──Pulsar push(规划)──▶  后端 device 模块
可选外设        ──环境/门磁/烟雾等事件────▶ (ASR/TTS/      └─ /mcp 直连 ──▶ ai-gateway
                                    智能体/WebRTC/OTA)
家属 App ◀── WebRTC 信令(P2P 通话) ── 涂鸦云
```

- 设备消息（上下线 / DP 上报 / 跌倒 / 对话）由涂鸦云统一中转。
- 后端通过**涂鸦 OpenAPI**（下行控制）+ **Pulsar 订阅**（上行事件）对接（当前为 mock，见 §5）。
- 视频通话走涂鸦 WebRTC（家属 ↔ 机器人 P2P）。

## 3. 后端 device 模块（当前 mock 版）

实体（6）：`device` / `device_binding` / `device_event_log`(dedup) / `device_dp_snapshot` / `device_online_history` / `device_config_log`（详见 `04`）。

API（`/devices`）：
```
GET    /devices/me/list              我的设备
POST   /devices/bind                 绑定（配网后 deviceId + 授权码）
DELETE /devices/bindings/:bindingId  解绑
GET    /devices/:id                  详情（含 DP snapshot）
POST   /devices/:id/dp               下发 DP（mock）
POST   /devices/:id/self-control     下发自控指令（mock）
POST   /devices/:id/ota/check|upgrade  OTA（mock）
GET    /devices/:id/events           事件流
GET    /devices/events/safety        安全事件
GET    /devices                      管理列表（admin）
POST   /devices/:id/mock-event       模拟事件（admin 联调）
POST   /devices/:id/mock-online      模拟上下线（admin 联调）
```

关键行为：`recordEvent()` 入库 + 自动同步上下线；`recordDp()` upsert snapshot + 落流水 + 同步电量。
**完全 mock、不依赖涂鸦 SDK**；接真实时只需新增 `tuya-openapi.service.ts` / `tuya-pulsar.service.ts`，**不动业务层**。

### 3.1 设备预留好的扩展点
`tuya_device_id` 唯一索引、`product_id`、`metadata`(JSON 兜底)、`device_event_log.dedupKey`(防重投)、DP 快照、在线历史、`TuyaSignatureGuard`/`DeviceContextGuard`、ALS 传 tenantId。

## 4. 告警分级与双链路（安全核心）

| 链路 | 走向 | 是否经 AI |
|---|---|---|
| **救命链路** | SOS/视觉跌倒/心率异常 → device → `alert` 规则引擎 → realtime 推家属 + 社区/人工升级 | ❌ 不经 LLM |
| **陪聊/查询链路** | 老人语音 → 智能体 → MCP → 业务 | ✅ 经 LLM |

告警事件 Schema（device → alert，不经 ai-gateway）：
```json
{ "eventType":"alert.fall|alert.sos|alert.heartbeat_missed|alert.medication_missed",
  "tenantId":1, "deviceId":"...", "targetId":"...", "severity":"info|warn|critical",
  "occurredAt":"ISO8601", "source":"vision|button|monitor|firmware|sensor",
  "payload":{ "confidence":0.92, "snapshotUrl":"...", "extra":{} } }
```
`alert.service` 流程：写 `alert_log` → 规则引擎评估升级 → realtime 推家属 → 严重级外呼/短信（规则决定，不由 LLM）。
后台「告警值班台」`admin/views/alert/duty.vue` + 跌倒事件流 `device/fall-events.vue` 可视化处置。

## 5. 固件规划（`firmware-companion-t5/`，待建仓库）

- 框架：Wukong AI 3.0 v3.13.6，Demo：`tuyaos_demo_wukong_ai`（语音+屏幕+摄像头）。
- 自控指令 `cmd_cb` 分发：表情（happy/thinking/listening/sleepy/worried）、动作（nod/shake）、人脸追踪（on/off）。
- **SOS 安全链路**：物理键中断 → `report_dp("sos",1)` → 涂鸦云直推后端 alert（不经 AI）。
- LCD 6 套表情序列帧；TF 卡断网降级语音（请服药/网络断开/电量低/SOS 已发出）。
- 涂鸦平台配置顺序（功能定义→硬件开发→智能体→AI 控制指令→自定义 MCP）见 [`16-硬件规格与配置（T5-E1）.md`](./16-硬件规格与配置（T5-E1）.md) §5。
