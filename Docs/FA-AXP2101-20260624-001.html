1. 摘要（Executive Summary）

被测 AXP2101 在 USB 输入正常（VMID≈5V、VBUS Good、I2C/寄存器/ADC 均正常）的前提下，充电 Power-Path BUCK（VMID → SW → 电感 → VSYS）完全未起振：无电池时 VSYS/SW 均为 0V；有电池时 VSYS 被钳在电池电压，无法充电。片内 DCDC4 等其他 BUCK 工作正常。外围充电电感 L3 阻抗正常（0.5Ω）。综合软件状态、硬件波形与分区对比测试，高度怀疑该颗 AXP2101 内部充电 BUCK 功率级或驱动电路损坏，而非外围元件或寄存器配置问题。

3. 故障现象

3.1 用户侧现象

#测试条件现象严重程度
P1仅 USB，无电池VSYS 始终 0V，MCU 无法启动致命
P2USB + 电池MCU 可启动，但电池不充电严重
P3仅电池MCU 可启动（依赖电池经 BATFET 供电）可 workaround
P4上电波形（早期）示波器见 VBUS 有 5V，VSYS 始终不上电与 P1 一致

3.2 期望行为

  • VBUS Good 后 RBFET 导通，VMID 建立，充电 BUCK 起振，VSYS 调节至 reg0x14 设定值（本板 4.7V）。
  • 无电池时 VSYS 应由 USB 独立供电，系统可开机。
  • 有电池时 VSYS > VBAT，电池电压应上升。

3.3 实际行为

  • VMID 正常（~5V），但 SW 无开关波形，VSYS 无法被 USB 拉起。
  • 有电池时 VSYS≈VBAT（supplement mode），系统由电池供电。
  • 芯片内部状态报告「CC 充电」，与物理测量矛盾。

7. 根因分析

7.1 直接原因

AXP2101 内部充电 Power-Path BUCK 功率级未起振或未输出，导致无电池无法建立 VSYS、有电池无法充电。

7.2 证据链

VBUS Good → VMID=5V → 充电 BUCK 应起振 → SW 应 PWM
    实测：无 PWM（有电池 3.5V / 无电池 0V）→ VSYS 无法升高

7.3 已排除项

怀疑项排除依据
I2C / 寄存器Chip ID=0x4A，读回无 FAIL
VBUS 输入ADC 5165mV，VMID 5V
TS 阻充电TS 已关闭
VINDPM / 限流vindpm=0，ilim=0
L3 损坏0.5Ω，非开路
整片 PMIC 失效DCDC4 有 PWM
软件未使能chg_en=1
电池 supplement 误判无电池复测仍 SW/VSYS=0V

7.4 故障定位

模块状态
VBUS / VMID / I2C / ADC正常
充电 Power-Path BUCK失效
DCDC1 / DCDC4正常
BATFET（有电池时）可工作，非根因

7.5 根因假设（供 FA）

  1. 充电 BUCK MOSFET 或驱动电路局部损坏（最可能）；
  2. 充电 BUCK 控制环路异常，状态机与功率级脱节；
  3. 制造/封装缺陷（模块级）；
  4. 批次可靠性问题（需厂家确认）。

8. 结论

  1. 充电 Power-Path BUCK 完全无输出，不符合 Datasheet §7.5.3。
  2. 外围 L3/C11/C5/C6 未发现开路或明显异常。
  3. DCDC4 正常，非整片失效。
  4. 无电池+USB 时 VMID=5V、SW=0V、VSYS=0V 为决定性证据。
  5. 建议厂家 decap FA，重点检查 VMID→SW BUCK 功率级。
