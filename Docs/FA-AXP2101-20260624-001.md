## 1. 摘要（Executive Summary）

被测 AXP2101 在 USB 输入正常（VMID≈5V、VBUS Good、I2C/寄存器/ADC 均正常）的前提下，**充电 Power-Path BUCK（VMID → SW → 电感 → VSYS）完全未起振**：无电池时 VSYS/SW 均为 0V；有电池时 VSYS 被钳在电池电压，无法充电。片内 **DCDC4 等其他 BUCK 工作正常**。外围充电电感 L3 阻抗正常（0.5Ω）。综合软件状态、硬件波形与分区对比测试，**高度怀疑该颗 AXP2101 内部充电 BUCK 功率级或驱动电路损坏**，而非外围元件或寄存器配置问题。

## 3. 故障现象

### 3.1 用户侧现象

| # | 测试条件 | 现象 | 严重程度 |
| --- | --- | --- | --- |
| P1 | 仅 USB，无电池 | VSYS 始终 0V，MCU 无法启动 | 致命 |
| P2 | USB + 电池 | MCU 可启动，但电池不充电 | 严重 |
| P3 | 仅电池 | MCU 可启动（依赖电池经 BATFET 供电） | 可 workaround |
| P4 | 上电波形（早期） | 示波器见 VBUS 有 5V，VSYS 始终不上电 | 与 P1 一致 |

### 3.2 期望行为（Datasheet / 参考设计）

- VBUS 插入且 Input Source Good（reg0x00[5]=1）后，RBFET 导通，VMID 建立，**充电 BUCK 起振**，VSYS 被调节至 Vsysmin DPM 设定值（本板 reg0x14=0x65 → **4.7V**）。
- 无电池时，VSYS 应由 USB 路径独立供电，系统可开机。
- 有电池时，VBUS > VBAT 条件下应进入充电，VSYS > VBAT，电池电压上升。

### 3.3 实际行为

- VMID 正常（~5V），但 **SW 无开关波形**，VSYS 无法被 USB 路径拉起。
- 有电池时 VSYS≈VBAT（supplement mode），系统由电池供电，**非 USB 供电**。
- 芯片 **内部状态机/report 显示「正在 CC 充电」**，与物理测量矛盾（状态误报或逻辑层与功率级脱节）。

## 7. 根因分析

### 7.1 直接原因

**AXP2101 内部充电 Power-Path BUCK（VMID → SW → L3 → VSYS）功率级未起振或未输出**，导致：

1. 无电池时 VSYS 无法从 USB 建立 → 系统不能启动；
2. 有电池时 VSYS 被 BATFET 钳在 VBAT → 无法形成 VSYS > VBAT 的充电条件 → 电池不充电。

### 7.2 支持证据链

```
VBUS Good (reg + ADC 5165mV)
    → VMID = 5V（RBFET/输入级 OK）
        → 充电 BUCK 应起振（reg0x18 chg_en=1, reg0x14 Vsysmin=4.7V）
            → SW 应出现 PWM ──实测：无 PWM（有电池 3.5V / 无电池 0V）
                → VSYS 无法升高 ──实测：0V（无电池）或 ≈VBAT（有电池）
```

### 7.3 已排除项

| 怀疑项 | 排除依据 |
| --- | --- |
| I2C 通信 / 寄存器未写入 | Chip ID=0x4A，读回校验无 FAIL |
| VBUS 输入异常 | ADC 5165mV，VMID 5V |
| TS 阻充电 | reg0x50=0x12，TS ADC 已关 |
| VINDPM / 输入限流顶死 | vindpm=0，ilim=0 |
| 充电电感 L3 损坏 | 下电测 0.5Ω，非开路 |
| PMIC 整片失效 | DCDC4（L14）有 PWM，DCDC1 可出 3.3V 供 MCU（有电池时） |
| 软件未使能充电 | reg0x18 bit1=1，日志明确 enabled |
| 电池 supplement 误判 | 无电池复测仍为 SW/VSYS=0V |

### 7.4 故障定位（Failure Localization）

| 模块 | 状态 |
| --- | --- |
| VBUS 输入 / UVLO | 正常 |
| RBFET / VMID | 正常 |
| I2C / 数字控制 / ADC | 正常 |
| 充电 Power-Path BUCK（SW 驱动 + 功率管） | **失效** |
| BATFET / 电池路径 | 有电池时可工作（supplement），非根因 |
| DCDC1 / DCDC4 等 | 正常 |
| ALDO/LDO 等（未逐一测波形） | 间接正常（系统功能部分可用） |

### 7.5 根因假设（供厂家 FA 验证）

1. **充电 BUCK 高侧/低侧 MOSFET 或驱动电路局部损坏**（最可能）；
2. **充电 BUCK 控制环路 / 起振逻辑异常**，数字状态已进 CC 但功率级未响应；
3. **芯片制造/封装缺陷**（如 EPAD/PGND 相关，但 DCDC4 能工作，倾向模块级而非全局 PGND）；
4. **批次/可靠性问题**（需厂家结合批次 FA 确认，我方目前仅 1 颗深度分析）。

---

## 8. 结论

1. 失效表现为 **AXP2101 充电 Power-Path BUCK 完全无输出**，与 Datasheet §7.5.3「VBUS Good 后 VSYS 应工作」不符。
2. 外围充电网络（L3=1µH、VMID 电容 C11、VSYS 电容 C5/C6）经电阻/电压测试 **未发现开路或明显异常**。
3. 同芯片 **DCDC4 正常工作**，说明 **非整片断电或全局 I2C 失效**。
4. **无电池 + USB** 条件下 VMID=5V、SW=0V、VSYS=0V，为 **决定性证据**，指向 **芯片内部充电 BUCK 电路失效**。
5. **建议厂家对失效样品做 decap / 功率级 FA**，重点检查 VMID→SW BUCK 相关 MOSFET、驱动、电流检测及起振条件逻辑。

## 9. 厂家复现建议（Reproduction Guide）

### 9.1 最小复现条件

| 项目 | 条件 |
| --- | --- |
| 样品 | 故障板上的 U4，或同批次 AXP2101 焊于同原理图 EVB |
| 输入 | USB 5V（VBUS），限流源 ≥500mA |
| 电池 | **先不接**（关键） |
| 负载 | VSYS 侧按原理图挂 C5/C6 等，不额外接大负载 |
| 通信 | I2C 读 reg0x00/0x01/0x14/0x18、ADC VBUS/VSYS |

### 9.2 必测波形/电压

| 步骤 | 操作 | 期望（正常芯片） | 失效样品实测 |
| --- | --- | --- | --- |
| 1 | 上电后测 VMID (Pin 36) | ~5V | ~5V（正常） |
| 2 | 测 SW (Pin 35) 波形 | PWM 开关 | 0V，无 PWM（异常） |
| 3 | 测 VSYS (Pin 34) | ~4.5~4.8V | 0V（异常） |
| 4 | 读 reg0x00[5] | vbus_good=1 | =1（正常） |
| 5 | 读 reg0x01[2:0] | 001/010/011 等充电态 | 010 (CC)（状态与功率不符） |
| 6 | 接入电池后再测 VSYS | VSYS > VBAT | VSYS ≈ VBAT（异常） |

### 9.3 对比测试（建议厂家同步做）

- 同板型 **良品 AXP2101** 替换 U4，重复 9.2 → 预期全部正常。
- 失效 U4 装 **厂家 EVB**（标准 1µH 充电电感 + 22µF×2 VSYS 电容）→ 若仍 SW=0V，则 **可排除客户 PCB 布局因素**。

## 11. 需厂家回复的问题

1. 在 **VMID=5V、vbus_good=1、chg_en=1** 条件下，**SW 仍为 0V** 时，芯片内部还有哪些使能/保护位或硬件条件需满足？是否存在 **已知 errata**？
